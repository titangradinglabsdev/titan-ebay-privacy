Titan eBay Repricing Agent

Privacy Policy

Last updated: October 19, 2026

Overview

Titan eBay Repricing Agent is a private inventory management application being developed for use with the owner's eBay seller account.

Information Processed

Once connected, the application is intended to retrieve current listing details, inventory information, and publicly available marketplace pricing information to evaluate and adjust listing prices.

Data Retention

The application is designed to process eBay marketplace data temporarily during each operation, without retaining historical listing data or buyer information after processing.

Authentication credentials required to maintain authorized access may be stored securely.

Data Sharing

The application is not intended to sell or share eBay marketplace data with advertisers or unrelated third parties. Cloud infrastructure providers may process information as necessary to operate the application.

Security

The application is intended to use encrypted connections and access controls to protect account authorization and marketplace information.
